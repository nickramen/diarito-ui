07 / Governance

Rules that keep the future React app consistent.

If a component exists here, screens use it. If a new variant is needed, it is added here first.

Component contract

One source of truth for visual decisions.

01
ReuseNever recreate a shared button, input, card, status, tab or modal inside page CSS.
02
ComposePages may arrange components with section, container, grid, stack and cluster primitives.
03
TokenizeNew colors, spacing or shape values become tokens before they become CSS literals.
04
React laterWhen the visual screens are approved, these classes map into reusable React components rather than being redesigned.
