Base design system

A smaller, clearer visual system for Diarito.

This library is the UI source of truth for the current HTML + CSS phase. It keeps brand decisions, component states, layout patterns, and Diarito-specific note patterns together without introducing app logic, authentication, backend services, or a UI framework.

Responsive base

Design the change in behavior, not just the shrink.

At narrow widths, three-column grids become one column, detail panels stack, documentation navigation moves into a compact menu, and the example app sidebar becomes bottom navigation. This mirrors the practical lesson from Korespeng without importing React or its application logic.

Baseline rule

Every new component should be checked at approximately 320px, 768px, and desktop widths before it joins the library.
