Breadcrumbs & pagination

Breadcrumbs for navigation context and compact pagination using system icons.

Breadcrumbs

Use breadcrumbs to show location context without competing visually with the page title.

PreviewHTML
FeedDaily entryDetail
<nav class="diarito-breadcrumb" aria-label="Navigation path">
  <a href="#">Feed</a>
  <span class="diarito-icon diarito-icon--sm" data-icon="chevronRight"></span>
  <a href="#">Daily entry</a>
  <span class="diarito-icon diarito-icon--sm" data-icon="chevronRight"></span>
  <span>Detail</span>
</nav>

Pagination

Previous and next controls use the system arrowLeft and arrowRight icons, not typographic characters.

PreviewHTML
<nav class="diarito-pagination" aria-label="Record pagination">
  <button type="button" aria-label="Previous page" title="Previous page" disabled>
    <span class="diarito-icon" data-icon="arrowLeft"></span>
  </button>
  <button class="is-active" type="button" aria-current="page">1</button>
  <button type="button">2</button>
  <button type="button">3</button>
  <button type="button" aria-label="Next page" title="Next page">
    <span class="diarito-icon" data-icon="arrowRight"></span>
  </button>
</nav>
