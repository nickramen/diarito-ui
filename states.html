States

Search and selection states that keep the same visual pattern from an empty field to a loaded result.

Search bar

The search bar is a normal system input with an integrated search icon. It does not need a card, internal title, or extra background.

PreviewHTML
<div class="diarito-search-field">
  <span class="diarito-icon" data-icon="search"></span>
  <input class="diarito-input" type="search" placeholder="Search by name, email, or code..." aria-label="Search records">
</div>

Empty search

When a search finishes with no matches, keep the same search bar and show an empty state directly below.

PreviewHTML

No results

We found no records matching “space weather”.

<div class="diarito-search-field">...</div>
<div class="diarito-empty">
  <div class="diarito-empty__icon"><span class="diarito-icon" data-icon="search"></span></div>
  <h3>No results</h3>
  <p>We found no records matching the search.</p>
</div>

Loading search

The loading state belongs to the search result. The search bar does not disappear or change structure.

PreviewHTML
Searching records…
<div class="diarito-search-field">...</div>
<div class="docs-search-loading" aria-live="polite">
  <span class="diarito-spinner" aria-hidden="true"></span>
  <span>Searching records…</span>
</div>

Searchable input / autocomplete

For relationships such as member, conversation, or recipient, use a searchable input and a matching-results panel. The user types a few characters and then selects a specific result.

PreviewHTML
No matches.
Type at least 2 characters and select a match.
<div class="diarito-form-field">
  <label class="diarito-label" for="member-search">Member</label>
  <div class="diarito-creatable-control">
    <span class="diarito-icon" data-icon="search"></span>
    <input class="diarito-input" id="member-search" type="search" autocomplete="off" placeholder="Type to search for a member...">
  </div>
  <div class="diarito-creatable-panel">
    <button class="diarito-creatable-option" type="button">Maria Fernanda Lopez</button>
