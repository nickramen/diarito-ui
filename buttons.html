Buttons

Variants, sizes, states, and iconography for actions.

Variants

Color follows the intent of the action. Buttons use no border or shadow; hover only changes the fill when appropriate.

PreviewHTML
<button class="diarito-button diarito-button--primary">Primary</button>
<button class="diarito-button diarito-button--secondary">Secondary</button>
<button class="diarito-button diarito-button--accent-1">Accent 1</button>
<button class="diarito-button diarito-button--accent-2">Accent 2</button>

Sizes & icons

Icons use Flaticon UIcons, just like the current shell.

PreviewHTML
<button class="diarito-button diarito-button--primary diarito-button--sm"><span class="diarito-icon" data-icon="plus"></span>Small</button>
<button class="diarito-button diarito-button--secondary diarito-button--icon" aria-label="Edit"><span class="diarito-icon" data-icon="edit"></span></button>
