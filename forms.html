Forms

Text, contact, date, quantity, selection, file, color, and state fields built with Diarito’s real controls.

Text, contact & search

Native types change their semantics, not the visual identity: same height, surface, radius, and typography. Controls use the approved one-pixel border and focus state.

Quantities, dates & time

Numeric and temporal inputs keep the same base control. Prefixes and suffixes are added as input groups, not as floating text outside the field.

PreviewHTML
%
$
<input class="diarito-input" type="number">
<input class="diarito-input" type="date">
<input class="diarito-input" type="time">
<input class="diarito-input" type="datetime-local">
<div class="diarito-input-group">
  <input class="diarito-input" type="number">
  <span class="diarito-input-group__suffix">%</span>
</div>

Selection

Selects, multi-selects, radios, checkboxes, and switches are chosen based on the number of options and decision type, without inventing screen-specific visual variants.

PreviewHTML
Visibility
Options
<select class="diarito-select">...</select>
<select class="diarito-select" multiple>...</select>
<label class="diarito-check"><input type="radio" name="mode"><span>Virtual</span></label>
<label class="diarito-check"><input type="checkbox"><span>Send notifications</span></label>
<label class="diarito-switch"><input type="checkbox"><span class="diarito-switch__track"><span class="diarito-switch__thumb"></span></span><span class="diarito-switch__label">Active</span></label>

Field states

Disabled, error, and helper text are states of the same control. We do not create visually different inputs for each screen.

PreviewHTML
Enter a valid email.
Helper text explains format or context without competing with the label.
<input class="diarito-input" disabled>
<select class="diarito-select" disabled>...</select>
<div class="diarito-form-field has-error">
  <label class="diarito-label">Email</label>
  <input class="diarito-input" aria-invalid="true">
  <span class="diarito-field-error">Enter a valid email.</span>
</div>
